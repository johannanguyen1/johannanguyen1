## ⭐ featured projects

<table width="100%">
<tr>
<td width="50%" valign="top">

### 🌐 [reliable transport protocol](https://github.com/johannanguyen1/tcp-ip)
`go` · `wireshark` · `docker`

user-space tcp/ip stack built from rfc 9293, achieving 3.6x higher throughput than the reference implementation (0.0416s vs 0.1509s for 1MB transfer). full tcp state machine, 4-tuple socket multiplexing, retransmission timers, and sliding-window flow control.

</td>
<td width="50%" valign="top">

### 🔐 [secure multi-candidate voting system](https://github.com/johannanguyen1/secure-multi-candidate-voting)
`c++` · `cryptopp` · `zkp`

extended a cryptographic voting protocol for k-of-n candidate selection under public-key encryption. hmac integrity verification and a custom zkp wrapper for client-side ballot verification without exposing selection vectors.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### ⚛️ [quantum entanglement benchmark](https://github.com/johannanguyen1/iqm-iquhack-2026)
`python` · `qrisp` · `iqm` — *3rd place, iquhack mit*

verified genuine multipartite entanglement across 12 qubits with a negative witness value of $W = -0.0585$ on real iqm nisq hardware.

</td>
<td width="50%" valign="top">

### 🏎️ [fsae digital dashboard](https://github.com/johannanguyen1/FSAE-driver-controls-digital-dashboard)
`c++` · `teensy 4.1` · `can bus`

brown formula racing's first digital dashboard, deployed on the 2025 competition car. spi driver for mcp2515 can controller (250kbps bus) with a tiered refresh scheduler (2hz rpm/gear, 1hz coolant, 0.2hz power).

</td>
