## 🌱 about me

I'm a junior at **Brown University** studying **Applied Math–Computer Science**, and I spend most of my time somewhere between the OS kernel and the network stack. I like software that gets its hands dirty — cryptography backends, embedded firmware, custom transport protocols — the kind of work where you have to understand *exactly* what's happening under the hood.

Right now I'm interning at **PreVeil**, where I've been unifying cryptographic backends across Desktop, iOS, Android, and Web into a single platform-agnostic interface. Before that, I spent a summer at **Pratt & Whitney (RTX)** writing verification software for jet engine control systems — which taught me a healthy respect for both fault tolerance and 8-hour manual calibration processes (and how to automate them down to under 10 minutes 👀).

What motivates me:
- 🔧 Building things that live close to the hardware — CAN bus, SPI, embedded MCUs
- 🔐 Cryptography and secure systems design
- 🌐 Networking from first principles (yes, I built my own TCP stack)
- 🧩 Making distributed/embedded systems that just *work*, reliably, at 2am during an unmonitored lab experiment

### 🌐 Reliable Transport Protocol (TCP Stack)
`Go` `Wireshark` `Docker`

Built a user-space TCP/IP implementation from the RFC 9293 spec, hitting **3.6x** the throughput of the course reference implementation (0.0416s vs. 0.1509s for a 1MB transfer). Implements the full TCP state machine, 4-tuple socket multiplexing, retransmission timers, and MSS-aware sliding-window flow control.

Also built a thread-safe socket layer with mutex primitives and channel-driven synchronization, then hunted down socket-state races and deadlocks using Wireshark packet tracing.

### 🗳️ Secure Multi-Candidate Voting System
`C++` `CryptoPP` `Zero-Knowledge Proofs`

Extended a cryptographic voting protocol to support k-of-n candidate selection, encoding ballots as bitmask vectors under public-key encryption to block tampering in transit.

Designed a single-submission ballot scheme to prevent time-based interference attacks, with HMAC integrity checks and a custom ZKP serialization wrapper so ballots can be verified client-side without ever exposing the selection vector.
